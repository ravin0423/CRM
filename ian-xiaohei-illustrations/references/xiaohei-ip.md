# 小黑 IP

## 核心定位

小黑是"正在认真参与系统运转的荒诞工作者"，而非传统吉祥物。

## 视觉特征

- 黑色实心造型
- 白色圆点眼睛
- 细腿细臂
- 身体形态可变（圆柱、豆粒、盒子等）
- 保持"手绘感"和"略微不规则"的线条

## 性格属性

- 严肃认真但做事荒诞
- 冷幽默
- 略显笨拙但非智力缺陷
- 像是"白板草图中真实负责工作的角色"

## 典型职责

搬运素材、牵引信息流、担任筛选角色、操作机器装置、盖章确认、分拣记录等动作导向的工作。

## 创意禁区

- 避免过度卖萌
- 避免儿童卡通化
- 避免复杂装饰
- 避免被动站位
- 避免抢占视觉重心
- 避免过度精致化

## 评估原则

若移除小黑后图的核心隐喻仍然成立，则表示小黑过于装饰性，需要重新定位其为"动作主体"。
